# Trained artifacts

Generated by `water-quality train`:

- `xgboost.json`: selected XGBoost candidate, including its best iteration.
- `mlp.pt`: selected PyTorch state dictionary, loaded with `weights_only=True`.
- `preprocessing.joblib`: training-fitted tree and neural transforms.
- `baselines.joblib`: fitted mean and Ridge references.
- `metadata.json`: architecture, chosen family, blend weight and calibration radii.
- `example_source_rows.json`: original row IDs linking inference examples to test predictions.

Use `water-quality predict --input examples/measurements.csv`. All measurements
must use the original headers and units. The default model was selected by
validation RMSE. Input review flags accompany predictions; interval coverage for
new patterns of missing sensors has not been established.

Load only artifacts you trust: joblib uses Python pickle. Models are supplied as
research outputs for source-index emulation; they do not certify water safety.
